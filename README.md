# ComplyEasy — B-BBEE compliance + tender intelligence platform

ComplyEasy helped South African SMMEs stay B-BBEE compliant and bid-ready. It grew into [Bidcheck](https://bidcheck.co.za) — the government-tender platform that finds tenders, checks eligibility (B-BBEE, CIDB, CSD, PSIRA), scores buyer payment risk and drafts compliant bids.

- **Live product:** [bidcheck.co.za](https://bidcheck.co.za)
- **Free tender search:** [bidcheck.co.za/search](https://bidcheck.co.za/search)
- **Guides:** [CSD registration step-by-step](https://bidcheck.co.za/blog/csd-registration-guide) · [How to get government tenders in South Africa](https://bidcheck.co.za/blog/how-to-get-government-tenders-in-south-africa)

## Status

ComplyEasy is archived as a separate product; its compliance engine lives on inside Bidcheck.
